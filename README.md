🚀 ESTAMOS CONTRATANDO ESTAGIÁRIO(A) — ENGENHARIA DE INTELIGÊNCIA ARTIFICIAL

📌 SOBRE A OPORTUNIDADE
Desenvolva soluções inovadoras de IA em uma das áreas mais estratégicas do banco: prevenção à lavagem de dinheiro, financiamento do terrorismo e combate a fraudes financeiras. Você vai atuar lado a lado com engenheiros de software, cientistas de dados, especialistas em IA, arquitetos e profissionais de negócio, construindo produtos com IA Generativa, Machine Learning, LLMs e automação.

🛠️ PRINCIPAIS RESPONSABILIDADES
• Apoiar o desenvolvimento de aplicações baseadas em IA
• Desenvolver e evoluir agentes de IA para atividades de PLD
• Construir integrações entre modelos de IA e sistemas corporativos
• Desenvolver APIs e serviços para consumo de LLMs
• Criar soluções com Retrieval-Augmented Generation (RAG)
• Apoiar pipelines de dados para aplicações de IA
• Desenvolver automações com Python e ferramentas Low Code
• Criar testes automatizados para soluções de IA
• Avaliar desempenho, qualidade e segurança dos modelos
• Apoiar iniciativas de MLOps e LLMOps
• Elaborar documentação técnica e disseminar conhecimento
